## Requirements

- **OS:** Linux  
  Developed and tested on Arch Linux

- **Compiler:** GCC with C++17 support

- **Build system:** Make

---

## Clone and Build

```bash
git clone https://github.com/Majkii2006/OBEngine.git
```

Then configure and build the project:

```bash
make build
```
Then run executable or do it by:
```bash
make run
```
